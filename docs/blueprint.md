# **App Name**: WebAssist

## Core Features:

- Basic Q&A: Provide pre-defined answers to frequently asked questions about website creation and API services.
- AI-Powered Chatbot: An AI tool that understands user queries related to website and API services, providing intelligent and conversational responses.
- Human Operator Connection: Option to connect the user with a live customer support operator for personalized assistance.

## Style Guidelines:

- Primary color: Saturated orange (#FF4500) to reflect energy and innovation, complementing the black theme.
- Background color: Very dark grey (#121212) to provide a sleek, modern feel.
- Accent color: Slightly desaturated yellow (#D4A274) to add a soft highlight.
- Font: 'Inter' sans-serif for clean and accessible interface text.
- Use minimalist icons with a focus on clarity and readability, ensuring they are easily understandable within the black and orange theme.
- Chat window should be designed for ease of use with a clear separation of messages and a prominent input field.
- Use subtle animations for message transitions and loading states to enhance user experience.
